# 2026-11-13 개발·검증 및 배포 절차 기록

최신 상세계획의 시나리오·지도와 입항·징수선·주점·선박 화면·운하·교역을 구현했다. 운영 배포 버전은 `2026.11.13-stories-harbors-tax`다. 사용자 배포 지시에 따라 공개 이력을 생성하고 점검 안내 대문을 먼저 게시했다.

## 이용 경로와 적용 규칙

- **항해자의 이야기**는 PC 상단, 모바일 더보기, 항해 의뢰 패널과 메뉴 찾기에서 연다. 초보 6장 30단계, 중급 두 편 각각 16단계, 고급 두 편 각각 20단계로 총 102단계다. 장별 대화·목표·진행 저장과 첫 완료 보상을 제공한다. 기존 네 의뢰의 진행·수령 기록도 유지한다.
- **보상**은 가상 부선장 아미나·이네스와 해협 상인의 인장·빅토리아 항해록이다. 기존 명부·가방·장착·공개 수집 카드·능력 계산에 연결했다. 초보 과정은 장마다 200 D씩 총 1,200 D이며 비용이 드는 기능 소개는 메뉴를 확인하면 된다.
- **교역**은 구매·판매 모두 한 거래 전량을 시작 단가로 계산한다. 구매량은 다음 구매 가격의 상승분, 판매량은 다음 판매 가격의 하락분에만 반영하며 현실 시간으로 회복한다. 기존 단일 압력은 부호에 따라 이관한다. 같은 항구에서 대량 구매 후 오른 판매가를 이용하는 차익을 막는다.
- **세금 징수선**은 소유 항구에서 50,000 D에 계정당 가상 1척을 구매한다. 항구 이름순으로 현실 30분 간격 순회하고 징수액의 5%를 수수료로 정산한다. 수수료의 소수 잔여는 이월하며, 오프라인분은 다음 접속 때 기존 기본 세수 72시간 한도 안에서 합산 정산한다. 직접 수령과 같은 장부를 사용하고 실제 선단 정원·보급을 차지하지 않는다.
- **운하 탭**에 자동 항해 시 운하 이용 체크박스를 넣었다. 설정은 저장되며, 켜면 자동 경로 계산 전에 운하 운영 상태를 확인해 경유하고 사용료를 정산한다. 꺼지면 운하를 제외한다. 기존에 운하 탭을 열어야만 운영 운하가 경로 후보에 들어가던 부분을 보완했다.
- **항구와 직접 입항**은 해상 45해리·강 18해리·공동 보급소 12해리로 완화했다. 같은 수로와 실제 물길을 검사하고 가까운 만·하구의 짧은 연결 경로를 허용한다. 직선거리 대비 크게 우회하는 육지 너머 접안은 제외한다. 접안점 탐색 간격을 0.025도에서 0.005도로 좁혀 해안에 더 가깝게 잡고 공통 표식·정박·도착에 반영했다.
- **내 배 보기**는 배 이미지와 선박 선택을 먼저 배치하고 선단·장비·조선/보관 탭으로 나눴다. 주점의 만날 사람 버튼에도 기존 최초 획득·고용 완료 기준을 적용했다. 같은 보급 경고는 한 장으로 갱신하며 모바일 조종 버튼과 겹치지 않게 배치했다.
