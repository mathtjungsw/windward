# 이전 업데이트 후속 기능 상세계획

[개선안](../IMPROVEMENTS.md)의 항구 운영 업데이트 뒤 남은 항목을 대상으로 한다. 현재 배포판에 있는 공개 공방·자동 포탑 연습, 서신 첨부금, 해적 의뢰 2종, 상주 부선장의 기본 세수 효과에서 이어진다. 제시한 시간과 횟수는 시범값이다.

## 현재 배포 상태

2026-11-15 공개 배포 커밋 기준으로 확인했다. 아래 상세계획은 오른쪽 열의 보완 사항에 적용한다.

| 4 | 공개 항구 공방, 자동 포탑, 사병, 기간제 운영권. 해상 전투의 포탄·내구도 연출 | 항구 공방 지도에 포탑과 점령 범위 표시, 참가자가 끊겼을 때 개별 복귀·종료 정산 |

## 3. 두 선장이 동의하는 항구 공방 연습

- **입장 흐름** — 경합 항구 화면에서 온라인 선장 한 명을 골라 초대한다. 초대는 2분 뒤 만료한다. 수락 후 준비 화면에 같은 연습용 선단·포탑·사병을 지급하고 각자 배치와 역할을 확인한다. 양쪽이 준비를 누르면 시작하며, 준비 대기 중에는 취소할 수 있다. 선장당 한 경기만 참가한다.
- **경기 규칙** — 공격측은 안쪽·바깥쪽 접근, 포탑 사격, 점령 유지를 선택한다. 방어측은 포탑 방향을 바꾸고 점령을 방해한다. 시범 경기는 최대 5분이며 공개 공방의 점령 진행 계산을 사용한다. 종료 시 승패와 이유를 둘 다 볼 수 있다. 연습만을 위한 경기 상태를 쓰며 지분·운영권·재산·실제 병력·해전 랭킹은 변경하지 않는다.
- **검증** — 중복 수락, 초대 만료 후 수락, 서로 동시에 초대, 게임 기록 복구 후 연습 재진입, 연습 결과로 실제 포탑·지분·화물이 바뀌지 않는지 확인한다.

## 4. 지도 위 공방과 연결 끊김 처리

- **지도 화면** — 공격선과 방어 포탑의 위치, 두 접근로, 사거리·점령 범위, 포탄 궤적, 배와 포탑 옆의 내구도를 표시한다. 모바일은 작은 상황 표시와 손가락으로 누를 수 있는 행동 버튼을 둔다. 기존 경기의 명중·내구도 변화와 포탄 연출 시점이 일치하도록 서버에서 확정된 행동을 화면에 재생한다.
- **서버 동기화** — 참가 중인 경기만 구독한다. 공격 행동·포탑 변경·점령 진행의 결과를 공유하고, 이동 보간과 포탄 효과는 화면에서 처리한다. 공개 공방 개시 시 운영 선장이 부재하거나 참여하지 않으면 현재 방식대로 자동 포탑으로 시작한다. 공개 공방 시작 예정과 재도전 가능 시각을 항구 화면에 표시한다.
- **연결이 끊기면** — 직접 참가 중이던 선장에게 60초간 복귀 시간을 준다. 돌아오면 이미 확정된 진행부터 이어간다. 한쪽만 유예가 끝나면 기권, 양쪽이 모두 복귀하지 않으면 무효로 처리한다. 처음부터 자동 방어였던 경기는 공격측 이탈 시 유예 뒤 기권 처리한다. 종료 결과는 경기 ID에 한 번 기록한다.
- **정산** — 연습은 승패와 종료 이유만 기록한다. 공개 경기의 승자는 기존 운영권 규칙을 따르고, 실제 손실은 참여 병력의 20% 상한을 적용한다. 자동 방어가 참가자의 개인 자원에 손실을 주지 않도록 한다. 상대가 오프라인인 상태의 정산은 공개 경기 장부에 먼저 기록하고, 해당 선장이 돌아올 때 자신의 자원에 한 번 합친다. 프로필 직접 접속이 필요 없는 경로를 검증한다.
- **검증** — 재접속, 강제 종료, 두 기기 조작, 중복 종료, 종료 직전 60초 유예, 기간제 운영권 만료와 새 과반 지분 확보, 결과 지연에서 지도와 확정 장부가 일치하는지 확인한다. 공개 공방 적용에 앞서 모의전에서 입력과 손실 방식을 검증한다.

## 5. 서신 차단과 읽지 않음 표시

- **차단** — 받은 편지함·선장 프로필에서 차단을 설정하고 해제한다. 차단한 상대가 새 서신을 보내면 발송 전에 종료하고 첨부금은 출금하지 않는다. 상대에게는 ‘현재 서신을 보낼 수 없어요’라는 상태만 표시한다. 이미 도착한 첨부금은 기존 수락·거절·반환 규칙에 따라 처리할 수 있다. 거래 재개 요청은 현재의 항구별 처리 흐름을 사용한다.
- **읽지 않음** — 새 편지가 있으면 더보기와 편지함 버튼에 작은 건수 배지를 둔다. 본문을 열면 읽음 처리한다. 발신자는 발송 상태와 두카트 처리 상태를 볼 수 있다. 읽음 상태는 수신자 계정에서만 사용한다.
- **저장과 검증** — 차단 여부는 발송 직전에 서버에서 다시 확인한다. 공개 대화나 항해 화면에 서신 내용을 표시하지 않는다. 배지 갱신에 필요한 요약만 읽고 편지함에서 본문을 필요한 만큼 불러온다. 차단 직전 동시 발송·차단 해제·중복 열기·기기 변경·첨부금 수락/취소/만료·타인 읽음 조회를 시험한다.

## 6. 해적 의뢰 진행 중 돌발 사건

- 기존 ‘밀수선 화물 회수’와 ‘표류 화물 수색’ 각각에 의뢰당 최대 한 번의 선택 사건을 연결한다. 밀수선 회수에서는 ‘흔적을 따라간다 / 원래 항로를 유지한다’를, 표류 화물 수색에서는 ‘떠다니는 짐을 추가로 확인한다 / 지정 화물부터 인도한다’를 제안한다.
- 사건 후보는 의뢰 수락 시 정한다. 실제 표시와 결과는 해당 조사 또는 회수가 확정될 때 기록한다. 사건을 무시해도 기본 의뢰는 완료할 수 있다. 선택에 따른 추가 보급 소모, 추가 이동, 보상을 버튼 위에 표시한다. 해적은 기존 규칙대로 플레이어가 교전을 시작하기 전에는 공격하지 않는다.
- 포기·기한 만료·구조 시 미처리 사건의 보상은 지급하지 않는다. 기본 보수와 추가 보수는 인도 확인 시 각각 한 번 정산한다. 동일 해역 재진입, 새로고침, 재출현한 해적과 과거 처리 기록의 혼동, 한 회수의 중복 보상, 보급 부족으로 선택을 건너뛰는 경우를 검증한다.

## 7. 상주 부선장 역할별 효과

- **배치** — 과반 지분을 갖고 정박한 항구에서 고용한 부선장을 직접 배치한다. 항구당 한 명, 부선장당 한 곳이다. 상주 중인 인물은 선단 승선 명단에서 현재 항구를 표시한다.
- **역할 초안** — 교역형은 기본 세수 5%, 탐험형은 정박 시 주점 소문 후보 한 건 추가, 전투형은 해당 항구 방어 포탑의 행동 대기 5% 단축으로 검토한다. 캐릭터 카드에서 상주 효과와 적용 조건을 보여준다. 기존 상주자는 이관 직전까지 쌓인 세수를 보존하고, 역할 적용 시점을 고지한다.
- **운영권과 회수** — 과반 지분을 잃으면 부선장을 명부로 돌려보낸다. 다른 선장이 기간제 운영권을 가진 동안에는 배치를 유지하고 상주 효과를 멈춘다. 만료 때 지분을 유지했다면 재개한다. 배치 해제·회수·정산은 진행 중인 가상 교역과 함께 확인한다.
- **검증** — 중복 파견·파견 중 승선·타 항구 배치, 과반 변경과 기간제 운영권 종료, 기존 세수와 미수령 위임 교역 보존, 소문 반복 열기와 공방 중 역할 변경을 시험한다.

## 8. 모바일 항해 진행창과 조사 버튼

- 첨부 화면에서 ‘주변 흔적 · 조사 열기’가 항해 진행창의 남은 거리·시간 영역을 가린다. 두 요소가 지도 하단에 각각 고정돼 있다. 모바일에서는 항해 진행창과 조사 버튼을 같은 영역에 배치하고, 두 요소가 모두 보이면 세로로 배치한다. 흔적 없이 항해하거나 정지 상태에서 조사만 가능한 경우도 현재 기능에 바로 접근할 수 있게 한다.
- 자동 항해 중 지도 배경을 누르면 표시되는 조종 모드 안내와 조사 버튼의 경로를 각각 검증한다. 조사 버튼을 눌렀을 때 지도 배경 클릭으로도 처리되지 않게 한다. 조사 목록을 열어 실제로 접근이 필요한 경우에는 기존 ‘조사 지점으로 이동’으로 진행한다.
- 모바일 320·390·430px와 PC에서 두 요소를 동시에 표시한다. 항해 진행률·남은 거리와 시간·일시 정지 버튼, 흔적 버튼을 한눈에 보고 각각 누를 수 있는지 확인한다. 자동 항해 중·일시 정지·정박·발견 팝업 후 복귀에서 확인한다.

## 적용 순서

1. 사적 서신 기능과 해적 의뢰 사건을 각각 검증한다.
2. 동의형 모의전에서 지도 연출과 연결 이탈을 시험한다.
3. 공개 공방에 검증된 지도와 정산 흐름을 연결한다.
4. 상주 부선장 효과를 기존 세수·공방·위임 교역과 통합 검증한다.

이전 상세계획의 확정 규칙은 [전체 교차 검토](PLAN_REVIEW_WINDWARD.md)를 따른다. 개선안의 과거 검토 사례는 연결된 개발계획과 출시 기록을 참조한다.
