# 바람의 항로 · 종합 랭킹 1위의 전 서버 축복

## 1. 발동과 만료

- 서버가 마지막으로 집계해 공개한 **종합 랭킹 1위 선장**이 효과 하나를 고른다. 종합 랭킹의 점수와 순위는 기존 집계 기준을 사용한다. 단일 항목 1위와 미집계 순위에는 발동 권한을 주지 않는다. 화면에 종합 랭킹의 집계 시각을 표시한다.
- 한국 시간 0시부터 다음 0시까지 **서버 전체에서 한 번** 발동한다. 발동 확정 시각부터 **현실 12시간** 지속하며, 발동한 선장을 포함한 모든 선장이 같은 효과를 받는다. 오프라인 경과를 정산할 때도 실제 적용 시간만 반영하고, 재접속해도 종료 시각은 그대로다.
- 발동 후 1위가 바뀌어도 효과는 만료까지 지속된다. 당일에 사용했다면 순위가 바뀌어도 추가 발동은 안 된다. 전날 효과가 자정 이후까지 이어지면 종료 뒤 그날 권한을 쓸 수 있다. 예를 들어 밤 10시에 발동했다면 다음 날 오전 10시까지 적용한다. 그날 쓰지 않은 권한은 다음 날로 이월하지 않는다.
- 적용 구간은 서버 시각 기준 **시작 시각 이상, 만료 시각 미만**이다. 발동 확인 시점에 서버가 권한과 남은 시간을 검증한다. 같은 선장의 여러 기기나 순위 교체 시점에 요청이 겹쳐도 하나만 인정한다. 유효기간 중 효과 교체·취소·중첩은 허용하지 않는다.

## 2. 효과 12종과 정산 기준

| 효과 | 변경 | 적용 경계 |
| --- | --- | --- |
| 전투 금지령 | 신규 자유 공격과 오프라인 선단 습격, 합의 결투, 해적 토벌, 공개 항구 공방 개시 금지 | 이미 열린 전투는 포격·후퇴·정산을 계속한다. 기존 결투 초대는 금지령 중 수락할 수 없고 기존 만료 규칙을 따른다. 항구 모의전·포탑 연습은 가능 |
| 자본주의의 축복 | 항구 교역품 판매 실수령액 +2% | 거래 확정 시점에 세금과 기존 효과를 반영한 실수령액에서 2%를 내림해 별도 가산한다. 일반 항구와 연결 항구의 창고 판매 및 최고가 견적에 적용한다. 세금·공동 시세·가격 압력은 현재 계산을 따른다 |
| 바람의 축복 | 바다 항해 속도 +10% | 자동·직접 조종의 해상 구간과 현재 선단 항해일 계산에 적용. 강·운하·구조 이동 제외 |
| 강물의 은혜 | 강 항해 속도 +15% | 자동·직접 조종의 강 구간에 적용. 일반 운하 통행 및 구조 구간 제외 |
| 풍년의 축복 | 항구 식량 보급비 −10% | 수동·입항 자동 보급에 적용한다. 기존 할인 뒤 보급 단가에 적용하고 보급 크레딧은 공통 정산한다. 같은 시점에 채웠다가 보급을 내리는 행위로 두카트를 벌 수 없게 검증한다 |
| 선원의 축복 | 항해 식량 소모 −10% | 정상 자동·직접 항해의 바다·강·운하 구간과 직항 보급 견적에 적용한다. 예약 보급이나 최대 적재량은 기존 값 사용 |
| 탐험가의 등불 | 탐험 흔적 포착 거리 +15해리 | 유효시간의 자동·직접 항해 탐지에 적용한다. 필요한 소문과 실제 조사 범위, 항구 탐지, 구조 중 발견 제한은 기존 조건 사용 |
| 기록가의 축복 | 새 도감 발견 명성 +10% | 조사 성공 기준. 보너스 정수값을 발견 기록과 함께 한 번 저장하고 내 도감·랭킹에서 합산한다 |
| 조합의 후원 | 일반 조합 의뢰 완료 보수 +10% | 인도·보고를 확정한 시각 기준. 일반 조합 의뢰의 두카트 보수에 적용하며 협동·이야기·항구 성장·해적 의뢰·도감 퀴즈는 기존 보수 사용 |
| 조선공의 축복 | 항구 선박 수리비 −15% | 수리 확정 당시 일반 수리비에 적용한다. 대포 개량과 전투 패배 손실금은 기존 계산 사용 |
| 상단의 축복 | 육상 운송의 편도 시간 −15% | 예약 확정 시 편도 시간에 적용하여 모든 왕복에 고정한다. 기존 최소 편도 30초 유지. 이미 예약한 운송의 도착·비용을 다시 계산하지 않는다 |
| 구조대의 후원 | 자동 구조비 −20% | 구조를 시작하는 시점의 구조비에 적용한다. 발견한 항구를 향하는 기존 목적지 선정과 구조 중 발견 제한을 유지한다 |

- 위 범위와 값은 초기안이다. 금액 보너스는 기존 효과를 모두 반영한 뒤 축복분을 한 번 계산한다. 할인 금액은 1두카트 미만을 내림하고 최종 결제를 0 D 이상으로 유지한다. 항해 속도·소모는 기존 선단, 부선장·장비, 구간 보정을 계산한 뒤 적용한다. 판매 보너스는 실제 순이익에 반영하고 거래 기록에서 축복 금액을 구분한다.
- 검색·견적에는 현재 효과와 만료 예정 시각을 표시한다. 확정 시점에 효과가 바뀌어 수령액이나 비용이 달라지면 새 견적으로 확인받는다. 최고가 판매처는 같은 검색 기준 시각으로 모든 항구를 비교한다. 출항 가능 거리와 시간은 실제 출항 직전 다시 확인한다.
- 항해·보급 효과는 진행 중에도 시작·종료된다. 자동과 직접 조종은 시간 구간을 발동 경계에서 나눠 계산한다. 예상 항해시간과 보급 필요량에도 실제 경과와 동일한 경계 계산을 적용해, 만료 직전에 출항한 선장에게 전 구간 혜택을 약속하는 상황을 방지한다.

## 3. 게임에서 사용하는 화면

1. **종합 랭킹** — 서버가 현재 1위로 집계한 선장에게 ‘오늘의 축복 선택’을 보여준다. 다른 선장이 볼 때는 현재 효과와 발동 선장, 남은 시간을 표시한다. 이미 사용했다면 다음 사용 가능 시각을, 전날 효과가 남아 있으면 그 만료 시각을 보여준다.
2. **선택과 확정** — 12종을 목록에서 고르면 적용 범위와 12시간 종료 시각을 미리 본다. 전투 금지령은 막히는 전투 유형과 기존 전투 처리까지 명시한다. ‘발동 확정’의 응답이 지연되면 활성 기록을 확인하고 결과가 확정될 때까지 중복 클릭을 막는다.
3. **게임 상단** — `바람의 축복 · ○○ 선장 · 7시간 24분 남음`을 표시한다. 작은 모바일 화면에서는 효과 이름과 남은 시간을 한 줄로 보여주고, 누르면 발동 선장과 적용 범위가 열린다. 별도 팝업을 강제로 띄우는 대신 전환 시점에 상단 상태를 갱신한다.
4. **내역과 도움말** — 종합 랭킹에서 최근 발동 기록을 볼 수 있다. 기존 웹 게임 설명서에 권한·종료·거래·전투 조건을 덧붙이고, ‘오늘의 축복’, ‘전투 금지령’, ‘1위 권한’으로 검색할 수 있게 한다.

## 4. 공유 저장과 검증 경계

- 공개 종합 랭킹의 `top/{선장 ID}/rank` 값을 서버가 직접 확인한다. 브라우저에 보이는 순위, 화면에 뜬 닉네임, 클라이언트가 생성한 발동 시각으로 권한을 판단하지 않는다. 집계가 비어 있거나 1위를 확정할 수 없으면 발동 유보와 사유를 안내한다.
- 작은 공유 상태에 효과 ID·발동 UID·집계 시각·발동/만료·한국 날짜·변경 번호를 저장한다. 하루 사용 여부와 활성 상태는 같은 서버 갱신에서 검사한다. 효과 ID는 정해진 목록만 허용하고, 종료 시각은 발동 시각에 43,200,000ms를 더한 값으로 고정한다.
- Firebase의 검증 시각을 이용해 날짜와 만료를 검사한다. 만료 후에는 읽더라도 적용하지 않으며, 만료를 위해 별도 예약 서버 작업을 두지 않는다. 접속 중에는 현재 효과의 공유 상태만 구독하고 카운트다운은 기기에서 계산한다. 내역은 최근 30건을 표시하며 화면을 열 때 가져온다.
- 전투 금지령은 화면 안내와 함께 신규 전투·오프라인 습격·NPC전·공개 공방이 저장되는 서버 경로에서도 검사한다. 기존 방에 대한 진행·정산을 분리한다. 금지령과 전투 개시 요청이 동시에 오면 서버가 먼저 확정한 순서를 적용한다.
- 경제 행동은 기존 개인 저장·공유 거래의 확정 흐름을 재사용한다. 사용한 효과 ID와 기준 시각을 확인하고 최신 효과와 다르면 새 견적을 안내한다. 기존 저장 본문만으로 값 전체를 서버에서 검증할 수 없는 경로는 범위를 명시하고, 초보 보호처럼 서버가 읽을 수 있는 공유 상태와 연결해 검증한다. 이전 클라이언트가 효과 또는 금지령을 건너뛸 수 있는지도 확인한다.

## 5. 개발 순서와 완료 기준

| 단계 | 검증 기준 |
| --- | --- |
| 1. 발동권과 공유 상태 | 1위만 성공. 2위, 미집계, 기기 두 곳, 집계 변경 동시 요청, 자정 이월, 12시간 경계, 응답 재시도에서 하루 한 번 유지 |
| 2. 상단 표시와 설명서 | PC·모바일에서 남은 시간이 읽히고 조작을 가리지 않음. 새로고침·중간 접속 때 활성 효과 복원 |
| 3. 교역·수리·보급·의뢰·구조 | 계산식, 여러 할인 조합, 세금·시세 원장, 종료 직전 견적과 확정, 재접속 후 지급 중복 방지 |
| 4. 항해·탐험·운송 | 바다↔강 경계, 효과 시작·종료 중 자동·직접 항해, 보급 예측, 탐지·조사 조건, 명성 재집계, 운송 예약 시각과 실제 도착 |
| 5. 금지령 | 온라인·오프라인 자유 공격, 합의 결투, NPC전, 공개 공방을 모두 새로 시작할 수 없는지 확인. 기존 전투 정산과 모의전이 가능한지 확인 |
| 6. 운영 | 테스트 Firebase에서 권한·시간·동시성을 확인한다. 운영 때 대문 공지, 잠시 접속 중단, 새 버전·규칙 확인, 서버 재개를 차례로 확인한다 |
