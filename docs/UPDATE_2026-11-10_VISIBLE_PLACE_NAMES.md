# 메인 지도 지명 가독성 · 2026-11-10

릴리스 `2026.11.10-visible-place-names`. 사용자 요청: 지명이 보이지 않는 문제를 즉시 개발·배포한다. 상태: 구현·로컬 검증 완료. 커밋 이후 GitHub Pages 공개 파일 반영을 확인한다.

## 원인과 변경

기존 방식은 이름의 고정 좌표와 글자 전체가 화면 안에 들어와야 표시했다. 리스본 중심 390×600 화면에서는 후보가 0개였다. 지명이 탐험 안개 아래에 있어 발견하지 않은 배경에서는 더 흐릿해졌다.

- 가까운 지명은 화면 안 여백 12px 안에 글자를 맞춘다. 원래 기준점에서의 이동은 일반 지명 최대 160 CSS px, 곶/해협은 최대 80px로 제한한다. 먼 점 지명을 임의로 끌어오지 않는다.
- 넓은 지리 영역은 기존 Natural Earth v5.1.2의 지역/해양 폴리곤으로 표시 범위를 판단한다. 화면의 후보 지점이 해당 폴리곤 안이며 구멍 밖일 때 이름을 배치한다. 경위도 경계 복사본은 원래 좌표로 감싸서 검사한다.
- `place-regions.js`(370,080 bytes)는 원본을 0.15도 허용 오차로 단순화한 장식용 데이터다. 기존 원본 이름 60개와 연결하며 지역 범위가 없는 점 지명에는 추가하지 않는다. 기존 생성기의 `build_labels()`만 실행해 지도/이동 데이터는 재생성하지 않았다. 경로/충돌/강/발견 계산에 이 폴리곤을 사용하지 않는다.
- 기준점이 먼 대륙 이름은 주변 반도·해협보다 나중에 배치해 넓은 대륙명이 가까운 지명을 밀어내지 않게 한다.
- 현재 표시 지점이 유효하면 기존 세계 좌표를 재사용해 작은 카메라 이동마다 글자가 화면 고정 지점으로 튀지 않게 한다. 180ms 묶음 갱신과 SVG 노드 재사용을 유지한다.
- 지명 레이어는 모든 탐험 안개 복사본 뒤에 그려지되 항로·항구·배보다 먼저 그려진다. 지명의 안개 가림을 없애면서 선박/항구를 덮지 않는다. 일반 14px·대양 16px, 진한 글자·밝은 4px 테두리·불투명 표시를 사용한다.
- 지명 표시 설정과 배·항구·선박·해적·다른 지명 겹침 방지를 유지한다. 지명 표시만으로 항구 발견·방문·탐험 점수가 오르지 않는다. 기존 설정을 임의로 켜지 않는다.
- 서버 경로·전송 주기·저장 형식·항해 성능 변경 없음. 지역 데이터도 기존 GitHub Pages 정적 파일이며 Firebase 읽기/쓰기를 추가하지 않는다.

## 검증

- 320/360/390/600/900px 너비와 260/320/600px 높이의 리스본 화면 15조합: 지명 표시, 테두리 안 배치, 배/항구/다른 글자와의 겹침 방지, PC/모바일 개수 제한.
- 북대서양 및 날짜변경선 양쪽의 대양 표시와 지역 포함 검사, 구멍 제외, 기존 세계 좌표 재사용, 먼 곶/전체 화면 장애물 제외, 모든 생성 폴리곤의 ID/유한 좌표/닫힌 고리 검사.
- DOM: 모바일 지도에 실제 text 노드 생성, 모든 안개 복사본 위/항구 아래 레이어 순서, 불투명·터치 방해 없음, 지명 표시 설정 끄기/켜기, 반복 갱신 중 진행 상태 불변.
- 기존 지도 조각/경계/자동·직접 조종/저프레임/미니맵 회귀 검사도 함께 실행한다.
- 실제 브라우저 화면 검사 도구가 초기화 중 `failed to write kernel assets` 오류로 시작되지 않았다. 따라서 실제 기기 화면·FPS는 확인하지 않았으며 DOM/좌표/계산 검증과 구분한다.
