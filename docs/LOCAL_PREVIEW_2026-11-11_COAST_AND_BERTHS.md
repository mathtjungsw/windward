# 바람의 항로 · 해도와 입항 정합성 로컬 검증

표시용 해안선과 작은 섬 자료로 항해 판정용 해안선을 구성한다. 기본 위도 간격은 0.025도이고 보스포루스의 세부 판정은 0.003도다. 같은 정적 해안 자료를 사용하므로 지도 판정용 네트워크 요청이 늘어나지 않는다. 넓은 바다에서는 기존 격자로 길을 찾고, 결과 경로와 접안 구간을 세부 해안에 대조한다. 다르다넬스와 보스포루스를 잇는 연결 구간은 실제 수역을 지나도록 검사한다.

항구 지도 표식, 미니맵, 자동 항해 목적지, 직접 조종 입항, 정박 및 구조 후 위치는 공통 접안점을 사용한다. 항구 설명의 원래 도시 좌표는 보존한다. 정밀 해안에 놓인 개발 후보지 5곳과 노란눈펭귄 관찰 지점 1곳도 바다 위로 옮겼다.

이전 저장에서 정박 중이면 같은 항구의 접안점으로 맞춘다. 항해 중이면 현재 위치에서 남은 항로를 다시 계산한다. 새 길이 없으면 안전한 위치에서 목적지를 다시 선택하고, 구조는 이전 구조비를 다시 받지 않는 기존 재계산 방식으로 이어간다. 좌표를 보정할 때 방문이나 발견, 보상은 처리하지 않는다. 재계산한 항로의 진행률은 현재 위치에서 다시 표시한다.

- 현재 주요 항구 78곳에 각각 이어지는 안전한 항로를 확인했다. 보존 항구를 포함한 접안점 112곳도 수역 판정을 확인했다.
- 리스본–포르투, 리스본–세비야의 시작 배 항로와 부산–나가사키, 이스탄불·벨그라드, 강 항구 진입을 검증했다.
- Chrome 모바일에서는 포르투 출발 항로의 양 끝이 포르투·리스본 표식과 같은 접안점을 가리키는지 확인했다.
- 작업 환경의 한 차례 점검에서는 해안과 전체 접안점 준비에 약 0.24초가 걸렸다. 두 대양 사이를 우회하는 일부 항로는 계산에 더 오래 걸릴 수 있다. 장거리 계산을 브라우저의 별도 작업으로 옮기는 검토는 남아 있다.

로컬 테스트에 적용했다. 실제 운영 계정의 저장·방어 장부와 새 접안점의 교차 검증은 배포 전에 별도로 남아 있다.
