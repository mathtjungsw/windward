# 2026-11-10 · 제안 게시판·소유 항구·지도 포격

사용자가 진행 중 작업을 계속하면서 이번 배포에 추가하도록 명시했다. 앞서 요청한 [14종 랭킹·평면지도·해적 연속 포격 수정](UPDATE_2026-11-09_RANKINGS_FIXES.md)과 합쳐 `2026.11.10-community-battle`로 공개한다.

## 이번 추가 범위

- **개선 제안 탭:** Google 로그인 선장의 공개 제안. 제목 50자·본문 1,200자, 서버 시각 기준 1분 간격. 최근 20개와 이전 페이지를 요청할 때만 읽고 상시 구독하지 않는다. 불확실한 전송은 동일 push ID를 확인해 중복 등록을 막고 초안을 유지한다. 게시글은 일반 이용자가 덮어쓰거나 삭제할 수 없으며 운영자는 Firebase 관리 권한으로 확인할 수 있다. 자동 메일·외부 메시지 발송은 추가하지 않는다.
- **소유 항구 탭:** 일반 과반 지분 항구·개발 항구의 이름, 소유자, 지분, 기본 세율, 지도 보기. 최대 124개 작은 공개 목록을 요청 시 조회한다. 지도 보기는 미발견 항구 입항·탐험 점수를 만들지 않는다.
- **원자 소유 목록:** 항구 소유·지분·세율 변경 때 `real/ownedPorts/{portId}`를 관련 저장과 함께 갱신한다. 정확히 절반으로 무소유가 되면 목록에서 지운다. 별도 위조 쓰기는 규칙에서 거절하며 다른 선장의 개인 저장은 건드리지 않는다. 기존 소유 현황은 공개 요약 전용 이관 도구로 보강한다.
- **지도 전투:** 해적선 선택·PvP 시작·재접속 때 전투 팝업을 띄우지 않는다. 항해 지도 아래의 독립 조작부에 대포·재장전·정산을 표시하며 접기/펼치기를 지원한다. 내 배와 시야 안 상대 배 옆에 HP 수치·막대를 놓는다.
- **포격 효과:** 원자 저장/방 참여자 구독이 확인한 결과로 포탄·포구·명중/빗나감·반격을 재생한다. 동일 PvP 사건 ID는 한 번만 재생하며 오래된 재접속 사건을 재생하지 않는다. 애니메이션이 피해·돈·명성을 변경하지 않는다. 시야 밖·화면 밖 표적에 효과를 그리지 않는다. 움직임 줄이기를 선택한 기기에서는 이동 효과를 생략한다.
- 후퇴는 지도 아래에서 패전 손실 문구를 확인하고 두 번째 클릭으로 확정한다. 기존 선제공격 금지·사거리·쿨다운·구조·손실 한도를 유지한다.
- PC 상단 메뉴와 모바일 더보기에 두 탭을 연결하고 안내 JPG 6·10쪽을 갱신했다. 나머지 안내도 최신 날짜로 다시 생성했다.

## 검증과 한계

- 전체 게임/저장/통신·DOM 테스트 **119개 통과**, 격리 Firebase Database Emulator 규칙 검사 **7묶음 통과**. 운영 선장으로 시험 전투·거래·제안을 발생시키지 않았다.
- UI 검사는 PC/모바일 폭의 CSS 계산값, 실제 버튼 연결, 제안 글 HTML 탈출, 불확실한 전송 재확인, 지도 보기의 발견 불변, 지도 전투 복원·포격·쿨다운·정산을 다룬다.
- 서버 검사는 작성자·타임스탬프·분량·분당 등록·덮어쓰기/삭제 차단·제한 조회·소유권 동시 변경·지분 변경·0% 외의 세율 목록 갱신을 포함한다.
- 실제 브라우저 도구는 `failed to write kernel assets (os error 3)`로 초기화하지 못했다. 실제 모바일 기기 화면·SMIL 애니메이션의 시각 품질은 직접 확인하지 못했으며 DOM/규칙 검사와 구분한다. 생성 JPG 6·10쪽은 이미지로 확인했다.
- 게시판은 읽을 때 최대 20개만 조회한다. 글은 채팅처럼 자동 소멸시키지 않으므로 장기 누적 저장량은 증가한다. 유료 서비스·Cloud Functions·요금제 변경은 추가하지 않는다.
