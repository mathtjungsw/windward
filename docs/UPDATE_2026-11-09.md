# 2026-11-09 통합 업데이트

구현 범위와 검증의 기준 문서다. 배포 상태·커밋·확인 결과는 `IMPLEMENTATION_2026-11-09.md`에 기록한다. 기존 시장·전투 계획과 11월 9일 추가 계획을 함께 적용했다.

## 접속과 기록

- Firebase의 `browserLocalPersistence`를 우선 사용한다. 같은 브라우저에서 로그인한 Google 계정을 복원한 뒤 기존 이름·항해 기록으로 자동 입장한다. 명시적 로그아웃은 로그인 유지를 해제한다. 저장을 지원하지 않는 환경은 세션·메모리 저장으로 대체한다.
- 동시 기기/탭의 기존 세션 보호는 유지한다. 자동 로그인은 살아 있는 다른 항해 세션을 자동으로 빼앗는 기능이 아니다.
- 선장 명부·상세에 `lastSeenAt`을 한국 시간으로 표시한다. 접속 중에는 현재 접속 상태를 표시하고 과거 누락은 ‘기록 없음’으로 둔다. 점수 수정 시각을 접속 시각으로 추정하지 않는다.

## 지도·탐험·선박

- 고정 배율 메인 해도, 지구본/평면 미니맵 선택, 클릭은 카메라 이동만 한다. 마지막 보기 선택은 기기에 보관한다. 북위 80도↔남위 60도 연결은 게임 규칙이며 미니맵 테두리를 경계에서 분할한다.
- 주요 항구 78곳, 호환 일반/과거 사전 112곳, 개발 후보 12곳 별도다. 유적 10·유물 14·동물 8·보물 8, 총 40종이며 발견 명성 합은 15,600이다. 실제 해안 유산은 관찰 기록, 신규 표류 유물은 창작으로 구분했다.
- 항구 정보는 80해리, 흔적은 100해리, 조사는 같은 바닷길의 60해리다. 기존 소문 조건·기록을 유지한다. 이동 구간의 흔적 진입에서 실제 이동분만 시간·보급으로 반영하고 큰 조사 창을 연다. 닫은 흔적은 같은 접근에서 재팝업하지 않으며 수동으로 다시 열 수 있다.
- `fleetShips`와 `flagshipId`로 배별 성장·기함을 보관한다. 예전 선단은 같은 현재 단계 n척으로 이관한다. 가장 느린 배의 속도·가장 낮은 보급/외해 성능을 적용하고 실제 항적에 꼬리 대형을 그린다. 다른 선단은 수신한 궤적까지만 그리며 육지 위 동행선은 숨긴다.
- 최대 5척, 개별 개량·같은 단계 일괄 개량, 한 척 추가 시 식량 나누기, 첫 뗏목 10일분과 6배 항해 속도를 유지한다. 과거 뗏목 전환 보상을 다시 주거나 기존 개량을 초기화하지 않는다.

## 공동 교역·항구·활동

- 가격은 서버 시각 보정된 현실 24시간 ±4.5% 변동과 공동 거래 압력으로 계산한다. 상자당 구매 +0.1%p/판매 −0.1%p, ±30% 한도, 분당 1.5%p 회복이다. 회복용 타이머 쓰기는 없다.
- 구매는 상자별 가격 합, 판매 한 건은 견적 시작 단가×전량이다. 5초 견적을 유지하고 그 사이 다른 거래의 revision 변경 시 재견적한다. 압력·재고의 다음 상태는 확정 시각으로 계산한다. 세금은 총액에서 별도 계산한다.
- 프리미엄 4종의 공유 재고는 생산지 최대 10상자, 2시간당 1상자 회복이다. 판매로 생산 재고를 복제하지 않는다.
- 일반 항구 최초 투자는 100만 D, 대형 항구는 300만 D, 추가 투자는 1만 D 단위다. 누적 지분 50% 초과만 소유하며 정확히 50%·과반 없음은 공동 투자 상태다. 원금 인출·지분 매매·배당은 제공하지 않는다.
- 기본 세율 0%, 소유자 본인·필수 보급·구조는 0%다. 소유자는 선장 이름을 골라 개별 세율 0~10%·블랙리스트 최대 20명을 설정한다. 소유권 변화 시 새 정책은 0%·제한 없음이며 이전 세금은 이전 수령인 장부에 남는다. 중립 보장은 리스본·포르투다.
- 개발 후보 12곳의 접근 수역에서 개척 200만 D·교역소 100만 D·조선 150만 D로 확장한다. 개발자가 소유하며 지정한 이름과 공유 상태를 동기화한다. 교역은 2단계, 선박 서비스는 3단계부터다.
- 연안 활동 12곳은 항구로 계산하지 않는다. 10해리 이내 정지 후 보급(24시간 간격·최대 2일·1.5배 가격)·약탈(한국 날짜 기준 하루 3회·보급 0.2일·성공 70%/200 D)을 이용한다. 실패 시 최대 HP 15%, 현금 5%/최대 500 D, 화물 5% 내림/최대 3상자를 잃는다. 고가 화물 약탈은 손해가 클 수 있음을 사전에 표시한다.
- 마카오·베네치아의 게임용 홀짝은 10~500 D·10 D 단위·5초 간격이다. 1~6 균등 주사위, 승리 시 베팅 포함 1.9배 내림, 실패 시 베팅금 손실이다. 회차·차감·결과·지급을 한 저장으로 확정한다.

## 대포와 전투

- 대포 8종×품질 5등급, 선박별 단계·포대·무게·적재 한도를 검사한다. 미장착 포함 최대 100개, 장착 최대 40문이다. 품질 개량은 차액, 매각은 가격의 60%다.
- 합의 결투는 피해 1.5배·명중 +10%p·재장전 0.7배로 임시 강화하고 항해를 멈춘다. 자유 공격은 같은 바닷길 시야 180해리 안에서 기본 성능으로 시작한다. 해적은 먼저 공격하지 않고 첫 포격 후에만 반격한다.
- 개인별 해적 6해역, 명성 50/150/400, 토벌 후 현실 30분 대기다. 카리브 해역은 실제 게임 수역 검사로 `[-77,19]`에 둔다. HP·발사·재장전·토벌 재출현은 저장해 재접속으로 초기화하지 않는다.
- 선박 HP는 `100+30×단계인덱스`, 선단 HP는 합계다. 결투 승자는 전투 전 HP, 자유 전투 승자는 남은 HP를 이어간다. 패배는 돈 10%/최대 2,000 D, 화물 10% 내림/최대 5상자, 완전 수리 기준 2%/100~3,000 D와 구조비를 정산한다. 돈이 없어도 이미 방문한 항구로 구조한다. 구조 중 발견·안개 제거·방문 보상은 금지하고 도착 시 HP를 복구한다.
- 사전 손실 보관금은 사용 가능한 돈·화물에서 분리하되 총 보유금·적재에 포함해 표시한다. 두 참가자 슬롯과 보관 스냅샷을 동시에 잠근다. 승자 보상은 실제 보관한 패자 금품에서만 계산하며 외국 계정의 개인 저장을 직접 수정하지 않는다. 회수는 개인 저장·수령 표식·슬롯/보관금 해제를 한 요청으로 처리한다. 남는 전리품은 피해자에게 남고 승자 수령 보관함은 50상자다.
- 항복·항구 이탈은 패전이다. 상대 접속 정보가 끊긴 뒤 45초, 제한 시간 180초 뒤 판정할 수 있다. 항구·구조·진행 중 다른 전투·패전 후 120초 보호를 적용한다.

## 저장·통신·운영

- 봉투 v5/게임 v4로 공통 이관한다. 원본은 각 기기에 별도 백업하며 현재 진행을 조용히 초기화하지 않는다. 미래 버전·잘못된 저장은 원본을 유지하고 중단한다.
- 자동 저장과 경제 작업은 같은 대기열을 사용한다. 개인 저장과 선택한 항구·활동·전투만 원자 반영하고 순번/revision/영수증을 교차 검사한다. 요청 전 로컬 영수증 보관에 실패하면 전송하지 않는다.
- 응답 유실 시 SDK의 낙관적 캐시를 확정 증거로 사용하지 않는다. 인증된 캐시 없는 서버 읽기로 확인하고, 확인할 수 없으면 저장·행동을 멈추고 새로고침 복구를 안내한다.
- 일반 선박 위치 최소 2초, 정지·명부 30초/90초 만료다. 로컬 확인 타이머 자체는 DB에 쓰지 않는다. 전투 위치/표시 변경은 두 참가자에게만 최대 4Hz, 발사·피해는 즉시 확정하고 재장전 숫자는 기기에서 그린다. 변화 없는 전투 프로필은 시각 필드만 갱신한다.
- 기존 Spark·GitHub Pages를 유지하며 유료 서버·Cloud Functions·결제 연결을 추가하지 않았다. 전투·거래는 사용량을 늘릴 수 있으며 무료량이 영구히 충분하다는 보장은 하지 않는다.
- 개인 JSON의 모든 경제 계산과 무작위 명중을 서버가 독립적으로 재계산하는 구성은 아니다. 친구 게임의 클라이언트 신뢰 모델을 유지하며 원자성·참가자·보관금 스냅샷·발사 순번·재장전·한 번의 정산을 규칙과 테스트로 보호한다.

## 검증의 범위

`npm test`, 생성물 검사, 로컬 Database Emulator 규칙 검사, HTTP 제공을 확인한다. 실제 운영 계정의 시험 교역·공격·보상 지급은 하지 않는다. UI는 Happy DOM에서 메뉴·팝업·선장 기록·미니맵 전환을 검사한다. 현재 컴퓨터/브라우저 검증 도구는 커널 경로 오류로 실행되지 않아 실제 Chrome/휴대폰 렌더링과 Google 로그인 후 브라우저 재실행은 직접 검증하지 못했다. DOM 통과를 실제 화면 검증으로 표현하지 않는다. JPG는 원고·수치 검사와 실제 생성 이미지 검토를 별도로 수행한다.
