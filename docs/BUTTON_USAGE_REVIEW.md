# 22번 · 버튼 사용 현황 분석

한국 시간 11월 7~13일의 기존 운영 서버 집계를 조회했다. 데이터가 있는 날짜는 11월 12일 8개 묶음과 13일 24개 묶음이다. 모바일 클릭 합계는 14,825건, PC는 1,745건이다. 같은 화면을 반복 조작한 건수를 포함하며, 노출과 클릭은 동일 시도에 대응하지 않는다. 정박 여부와 선장별 행동 차이를 이 비교에서 확인하지 않았다.

| 모바일 항목 | 노출 | 클릭 | 적용 |
| --- | ---: | ---: | --- |
| 더보기 | 72 | 563 | 하단 유지 |
| 항구·보급 | 72 | 483 | 하단 유지 |
| 주점 탭 | 116 | 355 | 하단 ‘화물’ 자리에서 정박 시 바로 열기 |
| 화물 바로가기 | 72 | 8 | 더보기와 기존 항구 화면에서 열기 |
| 항구 조합 | 49 | 137 | 더보기 상단 |
| 아이템 가방 | 49 | 68 | 더보기 상단 |
| 항구 찾기 | 48 | 59 | 더보기 상단 |
| 부선장 명부 | 49 | 34 | 더보기 상단 |

표본이 두 날짜에 집중돼 있어 낮은 사용량만으로 기능을 없애지 않았다. ‘주점’은 실제 주점 탭 클릭이며 소문 행 클릭과 집계가 다르다. 바로가기 편집이나 메뉴 제거는 개편 이후 추세와 필요한 접근 경로를 확인할 후속 후보로 남긴다.
