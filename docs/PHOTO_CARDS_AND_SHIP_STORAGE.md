# 실사풍 도감과 선박 보관

발견물 60종은 `dist/assets/discovery-photos/`에 목록과 상세 두 크기로 보관한다. 역사 선박 9종은 `dist/assets/ship-photos/`에 있다. 두 폴더에는 ImageGen 기본 도구로 만든 그림을 자른 WebP 129장이 있다. 도감 그림은 관찰을 돕는 재현 이미지다. 항해 지도에는 작은 배를 빠르게 구별할 수 있도록 선종 아이콘을 사용한다.

## 이미지 생성 기준

공통 프롬프트는 ‘정확히 등분한 독립 사진의 격자, 테두리와 글자 없음, 피사체를 각 칸 중앙에 배치, 자연광과 실제 재질, 작은 카드에서도 알아보기 쉬운 구도’였다. 역사 선박은 전체 선체가 보이는 사선 측면에서 나무와 돛 재질을 표현하고, 조선소의 선종 설명을 기준으로 돛대와 선체를 구분했다. 유적은 해당 유적과 해안을 담은 기록 사진 구도, 동물은 서식지와 몸의 특징이 보이는 야생 관찰 사진 구도, 유물과 보물은 해당 해역에 놓인 창작 물품의 근접 사진 구도를 사용했다.

생성 묶음은 역사 선박 9종, 아소르스부터 라파누이까지의 유적, 난마돌부터 고레섬까지의 유적, 해양 동물 14종, 유물 두 묶음, 보물 14종이었다. 발췌한 패널은 기존 발견물 식별자와 연결했다. 목록 이미지는 너비 192px와 최대 12KB, 상세 이미지는 너비 640px와 최대 60KB다. 그림은 게임과 함께 제공하며 Firebase에 저장하지 않는다.

## 도감과 항구

발견 카드를 누르면 배경 지역과 학습 설명이 열린다. 실제 유적과 동물은 참고 자료를 제공하고, 창작 유물과 보물은 가상의 이야기로 안내한다. 게임 발견 지점의 좌표와 ‘지도에서 보기’ 버튼은 내 도감에만 표시한다. 버튼을 누르면 지도 위치만 바뀐다.

내 배 보기에서 항구에 선박을 무료로 맡기고, 같은 항구에 정박했을 때 다시 찾을 수 있다. 항해 선단은 최소 한 척, 보관은 최대 24척이다. 맡긴 배의 최고 단계도 선단 한도와 역사 선박 해금 단계에 반영한다. 보관 선박은 항해와 전투에 참여하지 않는다. 배의 선종, 구입 원가, 내구도 비율을 보관한다. 장비와 대포는 선장이 계속 보유하며 장착 상태만 해제한다. 남는 선박에 화물을 실을 수 없으면 맡기기를 막는다. 맡기기와 회수는 기존 저장 거래를 이용한다.

주점에서 소문을 누르면 현재 항구 화면의 해당 소문 아래에 이야기가 펼쳐진다. 소문노트에서도 각 이야기를 목록 안에서 펼친다. 연결된 발견, 아이템 획득 또는 부선장 고용이 끝난 소문에는 접혀 있을 때도 ‘완료’를 표시한다.
