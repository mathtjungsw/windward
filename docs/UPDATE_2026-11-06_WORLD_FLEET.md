# 세계 탐험과 선단 업데이트 · 2026-11-06

## 구현

- 70개 주요 항구: 기존 54곳 유지, 34곳을 새 목적지에서 제외, 세계·섬 거점 16곳 추가. 과거 방문·정박·항해·화물 기록은 104곳 사전에 남긴다.
- 20단계 선박과 최대 5척 동행 선단. 새 선장은 통나무 뗏목·2,400 D·보급 10일. 사용자가 선택한 활성 항해 2초/일 속도 유지. 기존 3단계 선박은 5·10·16단계로 이관한다.
- 내 배 보기/다음 단계/전체 성장/선단 추가와 단계별 지도 그림. 개량은 전 선단에 적용하고 추가 시 식량 총량을 보존한다.
- 유적·유물·동물·보물 각 8개, 32개 자체 제작 그림. 난도별 50/150/400/1,000점, 총 12,800 명성. 주점 무료 소문·실제 접근·중복 수집 방지.
- 면적 기반 탐험 점수/개방률과 발견 명성 순위. 기존 세 기준과 합쳐 5탭, 선택 탭만 상위 5명 구독. 전체 선장 명부는 오프라인 포함 20명씩 읽는다.
- 구조/전환은 방문한 주요 항구만 선택하고 안개·항구/발견물·점수/보상을 중단한다. 재접속·재계획에 비용을 중복 청구하지 않으며 정상 이동 후 탐험을 재개한다.
- 작은 확인창은 내용 높이로, 큰 도감은 내부 스크롤. 좁은 모바일 메뉴의 가로 넘침 보완. 자세한 설명 JPG 7장과 ZIP은 `dist/guide/`에 공개하며 도움말에서 연결한다.

## 저장과 비용

저장 봉투 v3와 클라이언트 검증으로 구버전 저장을 보존 이관하고, Firebase 규칙으로 v3에 구버전 덮어쓰기를 막는다. 이관 전 본인 기록은 해당 기기에 백업한다. 새 공개 요약은 개인 저장 확인 후 변경이 있을 때만 갱신한다. 선단은 실시간 접속을 배 수만큼 만들지 않고 기함 단계/대수만 공유한다. 이미지와 섬 지도는 GitHub Pages 정적 파일이며 DB에 저장하지 않는다. 랭킹은 선택 탭만, 명부는 페이지 단위로 읽는다. 실제 서버 사용량 측정이나 0원 보장을 했다는 뜻은 아니다. 새 유료 서비스·요금제 변경·기존 이용자 삭제는 하지 않았다.

## 지도와 역사 설명의 한계

전체 항구가 실제 바다/강 경로에 연결되는지 검사했다. 섬에는 Natural Earth 1:10m 폴리곤 195개를 별도 표시한다. 우수아이아 부두와 이쓰쿠시마 관찰점은 단순화한 해안/수로 때문에 실제 위치와 차이가 있으며 게임 설명과 세계 콘텐츠 검증에 명시한다. 출처·관찰 좌표·180해리 이상 항로 간격 검증은 [세계 콘텐츠 검증](WORLD_CONTENT_VERIFICATION_2026-11-06.md)을 따른다. 역사 사실과 게임용 교역 배치·선박 성능·창작 보물은 구분한다.
