# 승격 항구 표시·랭킹, 도감·교역품 추가와 선박 보관

2026-11-17 · 구현과 배포 전 검토용

## 1. 승격 항구 이름

- 승격이 끝나면 지도와 항구 찾기에 `레이캬비크`처럼 지명을 사용한다. 승격 전에는 `레이캬비크 공동 보급항`으로 표시하고, 승격 후 시설 화면에서는 이름 아래에 `개발 항구 · 1단계`처럼 상태를 표시한다. 같은 규칙을 여섯 곳의 승격 후보에 적용한다.
- 지도, 항구 찾기, 즐겨찾기, 항구 상세, 소유 항구 목록, 목적지 안내, 세금 징수선 및 시세 검색은 한 곳에서 정한 표시 이름을 사용한다. 기존 등록 이름과 항구 ID는 보관하고 화면을 그릴 때 승격 상태로 표시 이름을 결정한다. 이름을 바꿔도 이미 정박 중인 선장과 즐겨찾기·투자·보급 기록은 같은 ID를 조회한다.
- 개발 후보 목록에서 승격 완료한 독립 후보를 누르면 실제로 운영 중인 승격 항구 위치를 보여준다. 저장된 항해일지 문장은 작성 당시 기록으로 취급한다. 항구 검색은 지명, 이전 표시 이름, 공동보급항 이름으로도 찾을 수 있게 검토한다.
- **검증**은 승격 직전과 1·2·3단계, 오래된 브라우저 저장 불러오기, PC·모바일에서 같은 이름과 기존 목적지·즐겨찾기가 이어지는지 확인한다.

## 2. 승격 항구를 항구 경영 랭킹에 집계

| 상태 | 소유 항구 목록 | 경영 수 추천 기준 |
| --- | --- | --- |
| 공동보급항 운영 중 | 과반 지분 선장에게 표시 | 0곳 |
| 승격 1단계 | 개발 항구로 표시 | 0곳 |
| 승격 2단계 · 교역소 개설 | 개발 항구로 표시 | 과반 지분 선장에게 1곳 |
| 승격 3단계 · 조선소 개설 | 개발 항구로 표시 | 앞에서 집계한 1곳 |

- **2단계를 추천한다.** 교역소를 열어 다른 선장의 교역이 가능해지는 시점이기 때문이다. 3단계 기준을 택하면 교역소를 운영하는 기간에도 집계가 보류된다. 기존 투자 지분으로 과반을 판정하며 정확히 50% 또는 과반 선장이 없는 공동 투자 항구에는 경영 수를 배정하지 않는다. 승격을 확정하거나 비용을 낸 사람과 과반 지분 선장이 다르면 과반 지분 선장에게 집계한다.
- 교역소 개설을 저장할 때 항구 ID별 경영 집계 기록과 공개 경영 수를 같은 작업으로 반영한다. 서버 규칙은 정식으로 개설된 항구와 등록된 과반 지분 선장을 확인한다. 같은 항구 ID에 한 번만 집계하고, 화면을 다시 열거나 여러 선장이 동시에 확정해도 추가되지 않게 한다. 기존 소유 항구 목록에서 같은 항구가 두 줄로 표시되는지도 확인한다.
- 이미 조건을 충족한 항구는 배포 점검 중 항구 등록 정보와 해당 공동사업 원장을 대조해 공개 경영 집계를 보정한다. 적용 전에 대상·예상 증감을 확인하고, 같은 보정 작업을 다시 실행해도 합계가 바뀌지 않게 한다. 일반·개발 항구 소유 수와 합쳐 표시하며 경영 부문 순위와 종합랭킹 갱신까지 확인한다. 선장 개인 저장을 다시 쓰는 작업은 필요하지 않다.
- **검증**은 과반 없음, 50%, 과반 있음, 확정자와 소유자가 다른 경우, 1→2→3단계, 기존 2·3단계 보정 재실행, 동시 확정을 포함한다. 배포 뒤 두 제안의 적용 결과를 확인해 게시판 상태를 갱신한다.

## 3. 발견 도감 12종 추가

- 탐험 중 흔적을 보고 기존 조사 버튼으로 등록한다. 난도는 1~2단계 5종, 3단계 5종, 4단계 이상 2종을 목표로 한다. 소문이 필요한 후보는 같은 시대에 접근 가능한 주점·항로를 연결한다. 소문 노트와 도감의 완료 판정, 구조 중 발견 차단을 기존과 동일하게 적용한다.
- 후보명과 다른 번역명, 실제 대상, 기존 ID를 대조한다. 랑스오메도 정착지와 멘도사 코덱스는 이미 등록돼 있다. 각 신규 카드에 발견 대상의 설명, 실제 장소 또는 소장처, 게임 조사 지점, 출처를 기록한다. 참고 자료는 [국립아시아문화전당의 하멜 자료](https://www.acc.go.kr/webzine/index.do?article=819&lang=en), [보들리언 도서관의 셀던 지도 자료](https://www.bodleian.ox.ac.uk/about/libraries/our-work/selden-map-conservation), [UNESCO의 칼라트 알바레인 자료](https://whc.unesco.org/en/list/1192/), [아조레스 지질공원의 세테 시다데스 자료](https://www.azoresgeopark.com/geoparque_acores/geossitios.php?id_geositio=39), [갈라파고스 보전기관의 가마우지 자료](https://www.galapagos.org/newsroom/the-worlds-only-flightless-cormorant-is-endemic-to-the-galapagos/)에서 시작한다.
- 이미지 재사용 조건을 원소장처에서 확인한다. 활용할 수 있는 사진·사료는 출처와 사용 조건을 기록하고, 사실적인 복원 그림을 쓰는 경우 그림에 그 사실을 표시한다. 목록용 WebP 12KB, 상세용 WebP 60KB를 목표로 삼고 상세 이미지는 열 때 불러온다.
- **검증**은 12종의 중복·좌표·항로·시대·소문 접근, 재접속 뒤 보존, 도감과 지도 표시, 새 항목의 전체·종류별 퀴즈 출제, 보상과 명성 중복 방지를 포함한다.

## 4. 지역 교역품 15종 추가

구버전 전용품과 항구별 한정품을 제외한 일반 교역품은 **114종 → 129종**을 목표로 한다. 후보 항구는 게임에서의 거래 배치를 뜻한다. 시대와 공급·수요의 역사적 근거를 확인한 뒤 배치를 확정한다.

- 상시 품목 5종과 시대별 2종을 배치한다. 구매 품목은 검증된 공급항에서만 판매하고 근거리·장거리 수요항을 비교해 시세를 조정한다. 품절이나 시간 변화로 의뢰 필수 품목을 구할 수 없는 경우가 생기지 않게 한다. 시대 전환 때 화물과 매입 원가를 보존하고 열린 거래 견적은 새 시세로 갱신한다.
- **저장 호환이 선행 작업이다.** 현재 거래한 품목 목록을 읽는 코드가 128개보다 긴 기록을 거절한다. 유효한 전체 상품 ID 수를 기준으로 검증하고 기존 거래 품목과 이미 수집된 한정품도 인정하도록 바꾼다. 서버의 공개 수집 랭킹 상한과 표시 기준을 함께 확인한다. 목록이 129개 이상인 저장으로 재접속하고, 재거래가 수집 수를 중복 증가시키지 않는지 확인한다.
- **검증**은 다섯 시대의 구매 가능 항구, 기존 의뢰 재료, 최고가 검색과 실제 매도액, 세금·초보 면세, 시대 전환 뒤 보유 화물 판매, 교역품 수집왕·종합랭킹 반영을 포함한다. 가격과 공급항은 기존 데이터에 추가해 지도 이동 중 새 서버 요청이 생기지 않게 한다.

## 5. 선박 보관 한도 제거와 작업 순서

- 이미 로컬에 반영한 24척 한도 제거를 다음 배포 범위에 포함한다. 25번째 배 보관, 재접속 후 회수, 승격 항구에 맡긴 선박의 저장 호환을 점검한다. 선단에는 최소 한 척을 남기며 최대 다섯 척까지 함께 항해한다. 회수에는 맡긴 항구 정박과 동행 선단 빈자리가 필요하다.
- 작업 순서는 ① 항구 이름과 경영 집계 ② 교역품 수집 저장 호환 ③ 도감·교역품 데이터와 이미지 ④ 통합 검증 순이다. 온라인 배포 때에는 공개 대문에 변경과 점검을 안내한 뒤 잠시 서버를 닫고, 새 버전·필요한 랭킹 보정을 적용한 뒤 접속을 다시 연다.
- **검토 기준.** 경영 수는 교역소가 열리는 2단계부터를 추천한다. 도감과 교역품 목록은 위 수량을 기준으로 하되, 역사 근거·자료 이용 조건·실제 게임 지형 확인 결과에 따라 개별 후보를 바꿀 수 있다.

칼라트 알바레인은 기존 딜문 도감과 겹쳐 수아킨으로 바꿨다. 브라질너트 대신 안나토 염료를 쓴다. 브라질너트의 대규모 교역은 참고 자료에서 더 늦은 시기로 확인했다. 투아타라는 기존 해상 조사 방식으로 접근한다. [수아킨 보전 기록](https://www.wmf.org/monuments/suakin) [CIFOR의 브라질너트 교역 조사](https://www.cifor-icraf.org/publications/pdf_files/Books/BAlexiades0701.pdf)
