# 정밀 해도 성능 개선 · 2026-11-10

릴리스 `2026.11.10-performance-map`. 사용자 요청: 이전 1·2·4 적용 후 속도는 괜찮지만 움직임이 끊겨 3번을 추가 적용한다. 상태: 구현·로컬 검증 완료. 커밋 이후 GitHub Pages 배포와 공개 파일을 확인한다.

## 구현

- 메인 지도 장식용 육지/국경/해안 그림자/강/음영을 원본 지리 좌표 그대로 사전 생성한 WebP 조각으로 바꾼다. 항구, 경로, 강 진입, 육지 충돌과 탐험 판정 데이터는 바꾸지 않는다.
- 1600×800 세계 좌표를 64단위로 분할, 마지막 남쪽 행은 32단위다. 고정 배율 12의 1 CSS px에 대응하는 12 pixels/세계 단위로 생성했다. 작은 섬 원본을 포함하며 각 타일에서 호수/구멍을 유지한다. 꾸밈 그리기에만 Shapely/Pillow를 사용하며 서버나 브라우저 의존성은 아니다.
- 지형 조각 237개 합계 3,018,010 bytes, 전체 약도 74,366 bytes다. 모든 조각을 처음부터 읽지 않는다. 화면 영역+16세계 단위 여유만 SVG image로 표시하며 같은 조각 노드를 재사용하고 떠난 조각은 제거한다. 파일별 해시를 URL에 넣어 캐시를 재사용한다. 조각 로딩 전에는 작은 전체 약도를 확대 표시해 빈 지형을 보완한다.
- 복잡한 지형 path 690개와 도형 문자열 약 5.84MB를 메인 SVG에서 제거하고 실시간 종이 잡음 필터도 제거한다. 전체 국경 GeoJSON 다운로드/파싱과 원본 음영 이미지의 별도 표시도 없앤다. 미니맵은 기존 방식과 캐시를 유지한다.
- 배경과 지명, 격자, 탐험 안개를 분리한다. 동서·남북 경계에 배경/안개/격자를 이어 붙이고 상세 조각도 주기 좌표로 배치한다. 지명은 가장 가까운 경계 복사본 좌표를 사용한다.
- 지명 재배치는 최소 180ms 간격, 8 CSS px 단위 변화 검사로 묶고 같은 글자 노드를 유지한다. 마지막 이동 뒤 예약 갱신을 한 번 실행한다. 큰 화면 이동/화면 크기 변경/지명 표시 설정은 바로 갱신한다. 설정상 PC 최대 16·모바일 최대 8개의 겹침 방지 배치를 유지한다.
- DB 경로·읽기/쓰기·위치 전송·보급·선박 속도·저장 형식 변경 없음. 새로운 유료 서비스 없음. 지형 자산은 기존 GitHub Pages의 정적 전송이다.

## 검증

- 추가 검사: 주변 조각만 요청/노드 재사용/이탈 제거, 동서·남북 연결과 마지막 행의 빈틈 없는 덮기, 지형 내 실시간 도형·지명·안개 분리, 60번 카메라 갱신의 지명/타일 노드 동일성, 날짜변경선에서 지명의 가장 가까운 복사본 좌표와 노드 재사용.
- 생성물 검사: 입력 지리·음영·강 파일, 생성기, 237개 타일·약도 해시 검사. 입력 해시는 Windows/Linux 줄바꿈 차이를 피하도록 관련 텍스트의 LF를 고정한다.
- 실제 생성된 포르투갈 해안 조각과 전 세계 약도의 이미지를 직접 확인했다. 로컬 게임/조각의 HTTP 응답과 DOM 조작은 별도 검사한다.
- Windows 화면 확인 도구가 현재 브라우저 주소를 신뢰성 있게 확인하지 못해 브라우저 UI 검사가 중단됐다. 실제 브라우저 페인트·모바일 FPS·체감 개선 수치는 검증하지 않았다.
