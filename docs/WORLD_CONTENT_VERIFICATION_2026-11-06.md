# 세계 항구·발견물 자산 확인 기록

2026-11-06. 게임의 세계 재배치·정적 콘텐츠 자산에 대한 기록이다. 운영 DB를 읽거나 수정하지 않았다. 기본 계획은 [세계·탐험 명세](WORLD_EXPLORATION_PLAN_2026-11-06.md)다.

## 항구 카탈로그

- `tools/world-catalog.json`이 원본이며 `node tools/build-world-catalog.mjs`로 `dist/world-catalog.js`를 생성한다. `--check`로 원본 일치를 확인한다.
- 현역 70개 ID = 기존 54 + 신설 16. 현역 제외 34개 ID는 삭제하지 않는 호환 기록 대상으로 명시한다. 합집합은 104개다.
- 권역 수는 유럽14/아프리카14/아시아16/북미8/남미8/오세아니아10이다. 이는 게임 항해 권역이며 미국령 하와이를 태평양권으로 묶는 등 국적과 구분한다.
- 신설 15곳의 도시 좌표는 기존에 보관한 [Natural Earth 10m populated places simple](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_populated_places_simple.geojson)에서 도시명/국가를 대조했다. 샌프란시스코와 발파라이소는 같은 이름의 다른 나라 도시를 제외하고 좌표를 선택했다. 항가로아는 라파누이 서쪽의 계획용 근사 위치로 두었으며 정밀 도시 측량 좌표로 소개하지 않는다.
- 실제 도시 위치는 `cityLon/cityLat`, 조작 지점은 `lon/lat`로 구분한다. 현재 0.5도 항해 격자가 좁은 만·해협을 생략하므로 보스턴27/아카풀코22/샌프란시스코31/발파라이소20/호놀룰루20/수바22/호바트32해리 정도를 바깥쪽 접근 지점으로 옮겼다. 우수아이아는 좁은 비글 해협을 생략해 약51해리의 오프셋이 있으며 항구 설명에 명시했다. 다른 신설 항구는 현재 격자에서 도시 근사 위치가 물 셀이다.
- 16곳 모두 물 셀이고 리스본의 물 접근 지점에서 경로가 존재하며 각 경로 선분의 육지 충돌이 없음을 규칙 테스트로 확인했다. 최종 선박의 90일 보급/5일 예비량으로 연결 가능하다. 실제 바닷길의 해도·수심을 검증한 자료는 아니다.
- 상품은 기존23종만 재사용한다. 모든 공급/수입/수요는 게임 설정이며 근거 없는 실제 생산지 주장은 넣지 않았다. 새 항구 설명은 우선 위치·바다·게임 역할을 중심으로 쓰고, 발파라이소/라파누이처럼 확인한 역사 자료는 따로 연결했다.
- 포르투 와인은 지역 공급, 건어물은 대표 공급으로 두고 리스본은 건어물을 수입한다. 두 도시 모두 실제 포르투갈 와인 공급 지역이라는 이야기와 게임 가격 계수를 구분한다. 두 도시의 와인을 모두 최저 가격으로 두면 첫 와인 판매가 손해가 되어 포르투의 게임 계수를 지역 공급으로 조정했다.

## 작은 섬 윤곽

- `tools/build-island-coasts.py`가 [Natural Earth 10m land](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_land.geojson)에서 관련 군도의 폴리곤을 골라 `dist/assets/islands.geojson`을 만든다.
- 아소르스·마데이라·카나리아·카보베르데·잔지바르·모리셔스·말루쿠·하와이·피지·타히티·라파누이·사모아·폰페이·갈라파고스·안다만을 포함한다.
- 195개 폴리곤, 127,191 bytes. 0.008도 허용 오차로 선을 단순화하고 원본의 내부 고리를 제거하지 않았다. 모든 고리의 닫힘·최소 꼭짓점 수·유한 좌표를 확인했다. 자료는 Natural Earth의 공용 지리 자료이며 외부 게임 그림이 아니다.
- 기존 굵은 해안선에 이 자료를 덧그리는 것과 실제 항해 격자의 충돌 판정은 서로 다른 검증 대상이다. 작은 섬 보급 거점의 해안 거리 보완용 점은 `ISLAND_COAST_POINTS`/원본 JSON의 `islandCoastPoints`로 제공한다.

## 발견물32종

- `dist/discoveries-catalog.js`에 유적/유물/동물/보물 각8종, 난도1~4 각8종을 등록했다. 점수50/150/400/1,000의 합계는12,800이다.
- 실제 유산/동물16종에는 짧은 한국어 설명과 기관 원문 링크가 있다. 유물8/보물8은 모두 창작 표시를 두었고 실제 출토품·난파선·매장 좌표로 소개하지 않는다. 일부 창작 물건은 보물찾기 분위기를 위한 것이며 돈으로 자동 환전하지 않는다.
- 난도3은 단서1개, 난도4는 서로 다른 항구의 단서2개를 사용한다. 총24개의 정적 소문이 있으며 제공 항구는 모두 현역 항구다. 조건·거리·점수는 게임 설정이다.
- 실제 장소의 근사 위치가 필요한 경우 `sitePoint`, 조작용 물 관찰 지점은 `point/lon/lat`로 구분한다. 이쓰쿠시마의 실제 근사 위치 부근 셀은 현재 격자에서 바깥 바다와 단절되어 있다. 시코쿠 육지 셀을 임의로 뚫는 대신 서남쪽 세토 내해의 연결된 물 지점 `[132,33.5]`를 사용했고 본문에도 단순화를 밝혔다. 실제 신사와 약50해리 차이가 있어 정밀 현장 관찰 좌표로 취급하면 안 된다.
- 아마존 펜던트는 기존 아마존 중심선의 `[-56.191762,-2.162449]`에 놓아 강이 아닌 인접 육지에서 조사되는 문제를 피했다.
- 32개 모두 물/기존 강 지점이며 리스본 물 접근점에서 실제 항로를 찾고 선분 충돌 없이 연결됨을 확인했다. 최종 선박 기준 가장 긴 추정은 헥터돌고래 관찰점까지56.36일로 90일/5일 예비량 안이다. 구조·단서·실제 수집 조작 검증은 통합 게임 테스트에서 별도 확인한다.

## 실제 대상의 주요 출처

2026-11-06 조회. 링크는 대상/지역/설명의 근거이며 가상 관찰점의 정확한 위치나 게임 난도의 근거가 아니다. 원문을 대량 복사하지 않고 설명을 짧게 다시 썼다.

- [UNESCO · 앙그라](https://whc.unesco.org/en/list/206/): 대양 기항 역할과 방어 시설.
- [UNESCO · 카르타고](https://whc.unesco.org/en/list/37/), [킬와](https://whc.unesco.org/en/list/144/), [마하발리푸람](https://whc.unesco.org/en/list/249/), [이쓰쿠시마](https://whc.unesco.org/en/list/776/), [랑스오메도](https://whc.unesco.org/en/list/4/), [라파누이](https://whc.unesco.org/en/list/715/), [난마돌](https://whc.unesco.org/en/list/1503/): 각 실재 유산의 존재·지역·짧은 교육 설명.
- [UNESCO · 발파라이소](https://whc.unesco.org/en/list/959/): 19세기 도시·항만 발전의 설명. 1522년 현황으로 바꾸지 않았다.
- [SANParks · 볼더스 아프리카펭귄](https://www.sanparks.org/parks/table-mountain/what-to-do/attractions/boulders-penguin-colony): 남아프리카 해안 관찰 지역. 해당 웹페이지의 오래된 개체수·보전 등급을 최신 수치로 복사하지 않았다.
- [NOAA · 지중해몽크물범](https://www.fisheries.noaa.gov/species/mediterranean-monk-seal): 지중해/동부 대서양 분포 개요. 게임 지점에 반드시 출현한다는 뜻이 아니다.
- [NPS · 케나이피오르 해달](https://www.nps.gov/kefj/learn/nature/sea-otter.htm): 알래스카 연안 분포.
- [돈솔 관광청 · 고래상어](https://www.donsol.gov.ph/whale-sharks.html): 필리핀 돈솔 관찰 지역. 실제 출현은 이동·해상 조건에 따라 달라짐을 설명했다.
- [갈라파고스 국립공원 · 바다이구아나](https://galapagos.gob.ec/monitoreo-de-seguimiento-para-estado-de-salud-de-las-iguanas-marinas/): 관찰/보전 활동.
- [뉴질랜드 보전부 · 뱅크스반도](https://www.doc.govt.nz/nature/habitats/marine/other-marine-protection/banks-peninsula/): 헥터돌고래 관찰 지역.
- [NOAA · 하와이몽크물범](https://www.fisheries.noaa.gov/species/hawaiian-monk-seal): 종 설명.
- [뉴질랜드 보전부 · 노란눈펭귄](https://www.doc.govt.nz/nature/native-animals/birds/birds-a-z/penguins/yellow-eyed-penguin-hoiho/): 남섬 오타고 등의 서식 지역.

## 검증 명령과 한계

`node tools/build-world-catalog.mjs --check`와 `node --test tools/world-catalog.test.mjs`로 생성물, 세계 수, 공급품/출처, 바다/강 연결, 단서 참조, 섬 윤곽 구조, 가까운 항구 간격, 초기 교역 수익을 검사한다. 이 검증은 운영 DB·실제 이용자·브라우저 화면·정밀 해상 안전을 검증하지 않는다.
