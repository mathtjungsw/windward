# 2026-11-18 · 칭호·항구 지분과 게시판 제안 6건

버전 `2026.11.18-titles-and-harbor-equity` · 저장 형식 20

## 반영 내용

- 탐험형 상주 부선장의 새 추가 소문은 실제 읽은 주점의 ID와 함께 개인 저장에 남겨 재방문·재접속 뒤 다시 읽는다. 과거 출처가 없는 기록은 기존 소문노트에 보존한다. 시대가 다른 과거 소문 재열람과 새 발견 조건은 구분한다.
- 판매창에서 효과 원천, 합산 전·후 수치와 3% 상한, 대상 상품·항구 제한을 확인한다. 향료용 이중 상자는 후추·정향·육두구에만 적용한다. 부선장 숙련을 포함한 실제 견적 함수를 재사용한다.
- 도감 25종 의뢰는 기존 대상 유적의 기록을 선택해 일괄 보고한다. 보고 3건과 500 D 지급을 같은 저장 작업으로 처리하고 수락·보고·완료를 구분한다.
- 새 칭호 22종과 기존 항해 기록가를 제공한다. 정박 중 효과 하나를 선택하며 기념 깃발은 유지한다. 칭호 효과는 판매·구매·항해·보급·수리·관찰·상륙·조합·NPC 계산에 연결한다. PvP에는 NPC 피해 효과를 적용하지 않는다. 공개 선장 상세에는 선택한 칭호만 표시한다.
- 2단계 이상 승격·개발 항구의 현금 지분 투자와 20% 손실 인출을 지원한다. 공용 소유자·지도 등록·경영 랭킹을 원자 변경하고, 기존 기본 세수와 미수령 수익은 지분 변경 시점에 분리한다. 원금을 모두 인출해도 시설·기존 귀속 수익은 남는다.
- 개설 당시 지분과 개발자 정보는 이력으로 보존한다. 개발항 최초 결제액은 확인되는 실제 납부액을 원금으로 인정한다. 미확인 구 항구는 창립 평가 지분 400,000 D와 인출 가능한 현금 0 D를 구분하며 이후 현금 투자는 정상 인출한다.
- 확장 동의는 지분 원장 버전을 포함해 투자·인출 뒤 재동의한다. 상주 부선장·자동 교역은 현재 과반 권한을 확인한다. 세금 징수선은 옛 미수령액과 신규 지분 항구를 이어서 회수한다.

## 검증

- 전체 게임 테스트 295건 통과. 새 검증 15건은 칭호 획득·선택·구 저장, 장비 상한, 소문 출처 정규화, 기존 발견물 보고·중복 지급 방지, 창립 지분·현금 분리, 과반·인출·세수 시점과 확장 동의 초기화를 확인했다.
- Firebase 에뮬레이터 전체 규칙 검사 통과. 새 `tools/check-harbor-equity.mjs`는 직접·승격 항구의 투자·인출, 소유자·랭킹·등록 갱신, 잘못된 소유자·타인 지분 수정 거절, 경합 revision 거절과 최소 저장 20을 검증한다. 기존 세션·시장·전투·공동수송·승격·소문 외교·축복 검사도 통과했다.
- `npm run notes:check`에서 생성물·자산 버전·지도·웹매뉴얼 일치를 확인했다.
- 실제 로컬 브라우저에서 칭호 선택과 사용 표시, 기존 도감 3건 보고 완료, 판매 합산 5.5% → 적용 3%, 개발항 투자 화면을 확인했다. 390px 모바일 화면에서 칭호와 수집 보상 버튼의 표시·스크롤을 확인했다. 샘플 상태만 변경했고 운영 계정으로 시험 거래·보고·투자를 실행하지 않았다.
