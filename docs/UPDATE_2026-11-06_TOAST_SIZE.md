# 모바일 알림 높이 수정 · 2026-11-06

사용자 캡처는 일반 팝업 대신 일시적인 출항 알림(`.toast`)이 화면을 길게 가리는 사례였다. 432×807 모바일 크기에서 실제 포르투 출항으로 재현했으며 알림 높이는 589.2px였다.

`style.css`가 지정한 top:148px와 `ux.css`의 bottom:70px가 동시에 적용되어 grid 컨테이너가 높게 늘어나고 자식 알림도 채워졌다. 모바일 규칙에서 top:auto로 해제하고 height:max-content, grid-auto-rows:max-content, align-content:end를 지정했다. 하단 안전 영역과 바로가기 위 간격은 유지한다. `index.html`의 ux.css 주소에 갱신 버전을 붙였다.

실제 브라우저의 격리된 게임에서 출항 버튼을 눌러 432×807, 390×844 크기의 동일 알림 높이가 41.6px인 것을 확인하고 화면을 보관했다. PC 1280×800에서도 알림 높이 44.4px와 기존 상단 위치를 확인했다. 서버 데이터에 시험 항해나 거래를 하지 않았다. 릴리스 표시는 2026.11.06-toast-fit이다. GitHub Pages의 기존 배포 경로로 게시한다.
