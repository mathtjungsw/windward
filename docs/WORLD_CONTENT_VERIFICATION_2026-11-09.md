# 세계 콘텐츠 확장 검증 · 2026-11-09

이 문서는 구현한 정적 카탈로그의 내용·항해 수역 검증 기록이다. 실제 배포 완료를 의미하지 않는다. 기존 항구·발견물 ID를 삭제하거나 이용자 진행을 변경하지 않았다.

## 범위

- 공공 목적지 카탈로그 70→78곳, 전체 과거 호환 항구 사전 104→112곳. 여기서 ‘공공’은 정적 카탈로그라는 뜻이며 중립 보장은 리스본·포르투 두 곳만 적용하는 최신 사용자 결정을 대체하지 않는다.
- 발견물 32→40종: 유적 10, 창작 유물 14, 동물 8, 창작 보물 8. 기존 32종은 이름·ID·보상을 유지한다.
- 발견 명성 합계 15,600, 난도별 항목 수 8/12/11/9, 소문 29개. 소문 요구는 기존처럼 난도 3에 1개·난도 4에 서로 다른 항구의 2개다.
- 흔적 100해리·조사 60해리를 모든 난도에 적용했다. 소문 보유 검사는 제거하지 않았다.
- 항구 개발 후보지 12곳, 연안 활동 지점 12곳. 경제 규칙·공유 상태는 별도 모듈에서 처리한다.

공식 자료는 위치·지리적 역할을 확인하는 데 사용했다. 전근대 상품 구성·생산/수입·가격은 별도의 게임 설정이다. 도시가 오늘 존재한다는 자료로 1522년의 시설·상품을 재현했다고 주장하지 않는다.

- [Natural Earth 원본 도시 자료](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_10m_populated_places_simple.geojson): 기존 로컬 `tools/source-data/places.geojson`의 도시 위치를 사용. 퍼블릭 도메인 지도 자료이며 동명이도시 밴쿠버는 캐나다 좌표를 선택했다.
- [밴쿠버 항만청 지도](https://www.portvancouver.com/wp-content/uploads/2018/06/5335_VFPA_Map_Source-Files.pdf): 항구·해협 위치 확인용 공식 지도. 게임 부두를 실제 현대 터미널이라고 소개하지 않는다.
- [Seward 시 항만](https://www.cityofseward.us/departments/harbor): 리저렉션만과 수어드 항구의 존재·위치 확인. 현대의 수리 시설을 과거 시설로 옮기지 않는다.
- [브라질 정부 항만 목록](https://www.gov.br/receitafederal/pt-br/assuntos/aduana-e-comercio-exterior/importacao-e-exportacao/recinto-aduaneiros/portos-maritimos-fluviais-e-lacustres): 벨렝·마나우스 등 실제 항만 존재 확인. 벨렝의 설명은 하구권으로 표현하며 현재 수로 전체를 사실적인 운항 경로로 주장하지 않는다.
- [갈라파고스 국립공원 산타크루스 역사 자료](https://www.galapagos.gob.ec/wp-content/uploads/downloads/2021/02/Historia-humana-Santa-Cruz.pdf): 푸에르토아요라가 산타크루스 남쪽 항구임을 확인. 현대 지명임을 게임 설명에서 구분한다.
- [이키케 항만청 위치 안내](https://epi.cl/puerto-de-iquique/ubicacion/): 칠레 북부 태평양 연안 위치 확인.
- [Darwin Port](https://www.darwinport.com.au/): 호주 북부 거점 확인. 현대 자원·시설은 게임 상품에 넣지 않는다.
- [Pohnpei Port Authority](https://www.ppa.fm/pohnpei-international-seaport/): 콜로니아 북쪽 석호의 항구 존재와 위치 확인.
- [Namport · Walvis Bay](https://www.namport.com.na/ports/39/): 나미비아 해안 항구의 존재와 위치 확인.

## 개발 후보지와 연안 활동

개발 후보는 세인트존스·레이캬비크·베르겐·카사블랑카·두알라·모가디슈·살랄라·치타공·다바오·케언스·더니든·코모도로리바다비아다. 실제 도시 지명을 추천 이름으로 사용하고 게임 시설·경제를 실제 역사 시설과 구분한다.

개발지의 부두는 공공 항구 78곳과 각각 최소 250해리, 개발 후보끼리도 최소 250해리를 유지한다. 가장 가까운 경계 사례는 카사블랑카 후보와 기존 항구 약 264해리다. 연안 활동 12곳은 실제 권역을 배경으로 한 **창작 활동 지점**이며 실제 마을·유적·주민 약탈을 의미하지 않는다.

## 확인한 검증

- `node --test tools/world-catalog.test.mjs tools/art.test.mjs`: 11개 통과.
- 24개 새 카탈로그 항구(이전 16+이번 8)의 부두가 수역이며 리스본에서 항해 경로가 연결된다. 경로의 모든 구간이 `Navigator.clear`를 통과했다.
- 발견물 40개도 같은 수역·연결 경로 검사를 통과했다. 기존 아마존 펜던트의 강 소속을 유지했다.
- 개발 12·연안 12지점의 수역·경로와 개발지 간격을 확인했다.
- 20개 선박·40개 발견물 SVG의 고유성·경로·중복 XML 속성·잘못된 숫자/외부 실행 내용 여부를 확인했다.

이 검증은 현재 축약 지도와 항해 격자의 프로그램 검사다. 실제 휴대폰에서 신규 항구마다 직접 조종해 입항한 검증이나 현실 항만 운항 검증을 대신하지 않는다.
