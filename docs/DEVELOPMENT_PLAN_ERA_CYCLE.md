# 바람의 항로 · 네 시대 순환 상세 개발계획

## 출시 범위

- 48시간 단위 네 시대, 시대 표시와 다음 시대 예고, 일반 교역품 100종, 도감 215종, 부선장 38명, 특수 아이템 100종을 연결했다. 기존 102종 이후 추가한 도감 113종에 사용 조건을 확인한 사진·소장 자료의 WebP 썸네일, 상세 이미지, 출처를 넣었다.
- 일반 항구와 개발 항구의 2단계 상품, 중립항과 공동 보급항의 공용 납품 및 현지 구매 화면을 연결했다. 항구별 물품 배정과 개별 품목의 역사 출처는 계속 검토한다.
- 책·기록 18종과 유물 6종에 실물 소장품 사진과 자료별 링크를 붙였다. 자연 분류에 피오르드, 삼각주, 석회암 탑, 갯벌, 순상 화산, 블루홀, 사구와 석호, 해안 주상절리 8종을 추가했다. [클리블랜드 미술관 Open Access](https://www.clevelandart.org/open-access)
- `npm run dev -- --emulators`로 로컬 서버를 띄운다. `?era=1`부터 `?era=4`까지 붙여 각 시대를 확인할 수 있다. 도감의 사진과 출처를 확인할 때는 계정 데이터 없이 열리는 `/__qa/inland-album?era=3`을 쓴다.

## 1. 공통 시대 시계

- 운영 설정에 시대 1의 시작 시각과 설정 버전을 보관한다. 시작점은 이번 업데이트 후 서버를 여는 시각이다. 서버 시각으로 시작점부터 지난 48시간 구간을 계산한다. 구간 번호를 4로 나눈 나머지로 현재 시대를 정한다. 시대 4가 끝나는 순간 시대 1이 시작된다.
- 네 시대로 8일에 한 바퀴를 돈다. 접속하지 않아도 시대는 진행한다. 기기 시각을 바꾸거나 다시 접속해도 결과는 같으며 개인 항해력, 보급, 이미 출발한 항로는 이어진다. 표의 연도는 콘텐츠 구성에 쓰는 역사 범위다. 화면의 항해력이 1400년으로 초기화되지는 않는다.
- 게임 상단에 `은과 도자기의 시대 · 1일 6시간 남음`처럼 표시한다. 누르면 다음 시대의 정확한 전환 시각, 교역 품목 변화, 발견물 분류별 단서를 볼 수 있다. 도감의 미발견 위치는 공개하지 않는다.
- 시대 데이터는 버전이 붙은 정적 파일로 배포한다. 공통 시작 시각과 설정 버전만 서버에서 읽으며, 시대 전환을 위해 항구 장부 전체를 자정마다 갱신하거나 접속자별 타이머를 두지 않는다.

## 2. 교역품 100종과 시대별 시장

1. 일반 품목에 고유 ID를 붙이고 분류, 원료·가공법, 기준가, 대표 산지와 소비지, 관련 시대, 출처를 관리한다. 기존 한정 특산품이나 가격만 다른 같은 상품을 100종 목표에 중복 집계하지 않는다. 분류별 초안은 곡류·농산물 18종, 가공 식품 15종, 가죽·모피 12종, 섬유·직물 15종, 목재·선박 재료 14종, 향료·염료 14종, 금속·도자기·공예 12종이다.
2. 각 항구·시대의 데이터에 **구매 가능 상품**, **공급 유형**, **매입가 계수**, **매도가 계수**, **시대별 수량 제한**을 기록한다. 공통 시장과 시대별 변경분으로 구성한다. 항구마다 초기에 1~3개 정도의 판매품 교체를 제안하고, 대표 품목은 시대마다 약 10종 배정한다. 한 시대에 사기 좋은 상품과 다른 시대에 팔기 좋은 상품을 섞어 항로를 다양하게 한다.
3. 시세는 기존 기준가, 생산·수요, 절대시간 시세 압력, 시대 계수, 세금·장비·축복과 같이 계산한다. 구입·판매 모두 확정 시점의 한 상자 가격을 전체 수량에 적용하고, 거래가 끝나면 수량만큼 다음 시세에 반영한다. 시대 전환이 기존 시장 압력을 초기화하지 않게 한다.
4. 주점·교역소·최고가 검색·창고 거래·자동 교역·조합 의뢰는 같은 시대표를 읽는다. 거래 견적에는 시대 구간 번호를 붙이고, 서버에서는 거래 확정 시각의 구간과 대조한다. 이전 시대 견적은 새 가격과 재고를 보여준 뒤 다시 확정받는다. 화면의 최고가 검색에는 조회 시점과 전환 시각을 함께 표시한다.
5. 시대가 바뀌어 교역소에서 판매하지 않는 상품도 선장이 보유 중이면 판매할 수 있다. 원가는 기존 화물에 기록된 값을 유지한다. 네 경계 모두에서 같은 항구의 전환 직전 구입→직후 판매가 손쉬운 반복 수익원이 되는지 시세 범위를 검증한다. 예외가 생기는 품목은 가격 계수를 우선 조정한다. 항구를 실제로 옮겨 얻는 시세 차익은 남겨 둔다.
6. 시대별로 리스본·포르투 주변에서 시작 선단으로 왕복할 수 있는 대표 항로를 마련한다. 공동 수송·진행 중 시나리오의 필수품은 조달처를 유지한다. ‘곡물’처럼 세부 품목으로 나뉘는 기존 의뢰는 호환 목록을 기록하고, 거래 처리와 납품 화면에서 같은 허용 품목을 쓴다. 기존 화물·납품량·보수와 공동 수송 하루 500상자분 한도는 유지한다.

## 3. 항구마다 성장 2단계 해금 교역품

| 항구 유형 | 2단계 해금 기준 · 제안 | 예시 |
|---|---|---|
| 일반 투자 항구와 대형 항구 | 기존 누적 투자금·조합 납품 성장 규칙 | 2단계인 나가사키는 이마리 자기 해금 후보 |
| 리스본·포르투 | 중립을 유지하고 공용 조합 납품으로 성장. 제안 기준은 항구별 누적 300상자이며, 선장별 하루 인정량 10상자 | 해금 전 필요 수량과 이미 납품한 양 표시 |
| 선장이 개척한 개발 항구 | 기존 시설의 교역소 확장 2단계 | 해당 후보지의 지역 대표품 판매 시작 |
| 공동 보급항 | 개항 후 공용 조합 납품 단계. 초기 기준은 중립항과 같은 300상자 | 지역 대표품 판매 항목을 보급 메뉴와 함께 접근 |

- 기본 항구와 활성화된 개발·보급항을 확인해 해금 품목이 빠진 항구를 찾는 검사 도구를 둔다. 신규 후보지도 활성화 전에 품목을 배정한다. 해금 품목은 기존 상시 품목과 교역소에서 구별하고, 잠긴 동안에도 품목과 조건을 볼 수 있게 한다.
- 일반 항구에서 새로 배정한 품목은 2단계에서 판매한다. **이미 2단계인 항구는 배포 시 기존 성장 기록을 읽어 바로 해금**한다. 기존에 일부 항구에서 1단계부터 팔던 한정품의 판매 자격은 유지하는 안을 추천한다. 새 해금 재고는 100상자 상한과 기존 구매 가능 재고 30상자 규칙을 재사용하는 안을 기본으로 검증한다. 시대 효과는 해금 자격을 없애지 않고 수요·가격을 조정한다.
- 신규 재고는 동일 항구에 여러 선장이 동시에 처음 들어와도 한 번만 초기화된다. 재고를 다 샀다가 탭을 열거나 시대가 전환되는 방식으로 재고가 재설정되지 않는다. 투자 인출로 성장 기준 아래로 내려가면 새 구매를 잠그고 기판매 화물을 보존한다. 중립항과 보급항의 공용 납품은 지분이나 소유권을 만들지 않는다.

## 4. 역사·자연 도감 215종과 시대별 발견

| 분류 | 목표 |
|---|---:|
| 유적 | 76 |
| 유물 | 40 |
| 책·기록 | 41 |
| 보물·난파선 | 15 |
| 동물 | 25 |
| 자연 | 18 |
| 합계 | 215 |

- **상시 190종, 시대별 6·8·3·8종**이다. 1400년 이전의 유적과 유물, 책과 자연 지형은 상시 목록에 둔다. 《집사》나 《굴리스탄》처럼 저작보다 늦은 시기의 현존 필사본을 소개하는 경우 두 시기를 본문에 구분해 적는다. 제작·전승 지역과 게임 속 조사 위치는 각각 표시한다.
- 항목에는 이름·분류·출처·실제 시대·지역·난도·시대 조건·발견 위치·소문·이미지 크레딧을 둔다. 실제 사진·유물 이미지의 사용 조건을 확인하고, 복원 그림에는 재현임을 표시한다. 발견 가능한 좌표를 검증하고, 구조 이동이나 시야 밖에서 발견이 기록되지 않는 기존 규칙을 적용한다.
- 현재 시대에 해당하는 흔적이 나타난다. 이미 조사를 시작했다면 시대 전환 후에도 조사를 마칠 수 있도록 진행 기록에 시작 시대를 붙인다. 미착수 흔적은 다음 순환에 다시 등장한다. 예전에 읽은 소문은 소문노트에서 다시 보고 `다음 등장` 상태를 확인할 수 있다. 기존 수집과 명성은 계속 유지한다.
- 전체·분류별 퀴즈를 각각 하루 한 번 푸는 규칙과 100 D 단위 올림은 유지한다. 현재 계수 **발견 수 × 95.5 D**를 적용하면 도감 215종을 모두 모은 선장이 전체 퀴즈에서 20,600 D, 전체와 6개 분류에서 모두 정답을 맞히면 하루 합계 41,500 D를 받는다.

## 5. 부선장 38명과 특수 아이템 100종

| 대상 | 신규 목표 | 배치 초안 |
|---|---:|---|
| 부선장 | 12명 | 마지막으로 아그리파, 바스쿠 다가마, 자크 카르티에, 아벨 타스만 추가 |
| 특수 아이템 | 34종 | 마지막으로 교역 장비 5종과 탐사·해상 활동 장비 5종 추가 |

- 고대 실존 인물을 포함한다. 아르테미시아 1세는 해전·호위, 피테아스는 항해·해도 후보로 둔다. 인물의 실제 시대와 만나는 게임 속 시대를 구분한다. 확인이 어려운 행적은 출처와 기록 범위를 함께 표시한다. [헤로도토스의 아르테미시아 기록](https://sourcebooks.fordham.edu/ancient/480artemisia.asp) · [피테아스의 현존 기록 연구](https://www.cambridge.org/core/books/abs/geographers-of-the-ancient-greek-world/pytheas-of-massalia/32E5E5D0F603A690931494A0B15BD1DF)
- 부선장 고용은 주점 소문과 지정 항구 방문, 화물 제출, 발견·해적 토벌 등 역할에 맞는 조건에 연결한다. 추가 장비는 같은 경로로 얻는다. 아그리파, 아르테미시아, 피테아스의 소문은 네 시대 모두에서 들을 수 있다.
- 주점은 현재 항구의 소문을 보여주고, 읽은 소문은 소문노트에 모인다. 소문만으로 부선장·아이템·발견물이 구별되지 않게 한다. 이미 획득한 보상은 완료 표시하고, 예전에 읽은 소문은 숨김과 다시 보기를 사용할 수 있게 한다. 한 번 획득한 장비와 고용 인물은 시대가 달라져도 이용한다.
- 기존 동행·항구 상주 규칙과 장착 한도를 유지한다. 예를 들어 교역 장비는 수수료·적재·거래 선택지를 다양화한다. 같은 능력 여러 개를 장착했을 때 무한 할인이나 이익 반복이 생기지 않는지 확인한다. 효과 표와 실제 적용 수치가 같아야 하며, 다른 선장의 공개 카드에서도 인물·장비 능력과 게임 내 획득 좌표 공개 범위를 구분한다.

## 6. 구현 순서와 검증 기준

1. **데이터와 출처** — 100종 교역품과 항구별 구매·수요표, 항구당 해금 상품, 도감 215종, 부선장 38명, 아이템 100종을 기준으로 검사한다. 출처·이미지 사용 조건·시대 분류·획득 경로를 확인한다. 오래된 ID를 삭제하거나 다른 대상에 재사용하지 않는다.
2. **공통 시계와 시장** — 서버 시각을 사용해 시대를 계산하고, 4→1을 포함한 전환 직전·직후·경계 순간에 두 기기에서 같은 시대를 보는지 검사한다. 구 견적, 중복 확인, 비동기 저장 실패, 재접속에서 두카트와 화물의 일관성을 확인한다.
3. **성장과 수집 흐름** — 다섯 항구 유형에서 잠금과 재고를 비교하고, 기존 나가사키와 미성장 항구를 포함한다. 같은 시대와 다음 순환에서 각각 발견·고용·아이템 획득을 시험한다. 진행 중 조사, 열린 퀴즈, 소문 완료, 진행 중 의뢰, 다른 선장 공개 카드도 확인한다.
4. **저장과 화면** — 기존 화물 ID와 원가, 소유권·도감·장비·부선장 ID와 명성을 이전 버전 저장본으로 검증한다. 신규 목록을 모르는 이전 버전의 저장 덮어쓰기를 차단하고, 기존 운영 규칙의 저장 크기와 신규 ID 검증 한도를 점검한다. PC·모바일 교역소에서 현재 시대, 다음 시대, 잠금 조건을 확인한다. 이미지와 상세 설명은 필요한 항목만 불러오고, 품목·도감 검색에는 이미 불러온 정적 목록을 재사용한다.
5. **수치와 공개 준비** — 시대별 초보 교역과 장거리 항로를 비교하고, 항해 기간·현실 접속 간격·퀴즈 성장에 따른 수익을 표로 검증한다. 운영에 쓰기 전에 합계 수량, 모든 항구 해금 품목, 모든 시대의 필수 의뢰 조달 경로, 출처와 획득 조건이 채워진 것을 확인한다. 배포 지시가 들어오면 점검 안내 게시, 서버 일시 차단, 배포와 확인, 재개 순서로 진행한다. 새 기록이 생긴 뒤 문제를 되돌릴 경우 기존 기록을 읽을 수 있는 카탈로그 버전을 유지하며 시대 효과를 끌 수 있게 준비한다.

## 수치 검토가 필요한 부분

- 중립항과 공동 보급항의 공용 납품 300상자, 선장별 하루 10상자는 초기 제안이다. 2단계를 언제 경험할 수 있는지 기존 접속 규모에 맞춰 검토한다.
- 교역품별 공급항·수요항·가격과 획득 조건, 도감·부선장·아이템 전체 명단은 개별 출처와 좌표 검증 후 확정한다. 이 문서의 테마와 분류별 수량은 그 목록을 만들 때 적용할 기준이다.
- 퀴즈 보상 계수, 시대별 수익 상승 폭, 첫 운영 시대의 한국시간 기준점은 시뮬레이션과 운영 검토 후 확정한다.
