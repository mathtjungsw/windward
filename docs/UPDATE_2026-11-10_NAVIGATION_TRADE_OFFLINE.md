## 저장·동시성

저장 봉투는 v6, 기존 게임 데이터 v4에 선택 필드를 확장했다. 구버전 저장의 돈·화물 원가·배별 ID·대포·보급·발견·소문·안개·투자·최종 접속 시각을 보존한다. `config/minSchema=6` 전환 뒤 오래된 화면의 저장·경제 쓰기와 레거시 위치 게시를 차단한다.

`fleetStates/{uid}`는 본인 자산/위치와 누적 전투 결과를 분리한다. `shared/raids/{id}`의 전투 revision, 양쪽 HP/쿨다운/누적 보상·보관금 소비, 전투 슬롯과 본인 개인 영수증을 같은 루트 변경분으로 확정한다. 타인의 개인 저장을 읽거나 수정하지 않는다. 새 자동 저장은 장부 순번이 맞을 때만 허용하고 본인 재접속 시 한 번 반영한다. 공격자의 연결이 끊겨도 반격 피해와 손실을 양쪽에 남긴다. 패전 선단은 영구 위치 목록에서 제거하고 실제 방문 항구로 구조하며, 원래 보관금 원금을 여러 전투에서 중복 반환하지 않는다.

이동은 2초, 정지·접속 유지 30초다. 개인 `privateNavigation/{uid}`는 확정 저장 revision/항로 식별자와 작은 신규 탐험 비트만 저장한다. 항로 변경·취소는 먼저 전체 저장하고 다른 항로에 진행 거리를 적용하지 않는다. 주변 `fleetIndex`는 100개 키 페이지를 이어 구독해 오래된 오프라인 선장을 시간순 제한으로 누락하지 않는다. 지도에는 거리순 29개를 우선 표시한다.

최초 등록은 **한 번의 관리 작업**이다. 필요한 여러 경로의 원자 등록과 구버전 차단을 함께 하기 위해 `gameV2`를 비공개 백업하고 ETag 조건부 루트 PUT을 쓴다. 중간에 다른 쓰기가 끼면 412로 거절하고 최신 원본을 다시 계산한다. 평소 게임이나 최고가 검색에 전체 루트 읽기를 추가하지 않는다. 이관 경계의 미전송 기기 저장은 정확히 해당 원본 revision일 때만 새 보관금을 보존하며 한 번 복원한다.
